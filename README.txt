ЯК ОТРИМАТИ APK

1. github.com -> New repository (Public), назва: vypusk.
2. Upload files: завантажте ВСІ файли цього архіву (index.html, manifest.json, sw.js, папку icons).
3. Settings -> Pages -> Branch: main, папка / (root) -> Save.
4. Через 1-2 хв сайт буде на https://ВАШ_НІК.github.io/vypusk/
5. Відкрийте pwabuilder.com, вставте це посилання -> Package for stores -> Android -> Generate.
6. Завантажте zip, у ньому є файл .apk. Скопіюйте на телефон і встановіть (дозвольте встановлення з невідомих джерел).

Без APK: відкрийте посилання з кроку 4 у Chrome -> меню ⋮ -> «Установити застосунок».
